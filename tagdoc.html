Rexcel - Taglang

Last updated: Sunday, July 5, 2026

1. Introduction

Rexcel's Taglang (name pending) is a simple templating language used with the r!tag command. Using it, you can create dynamic content by embedding expressions directly into your text.

2. Operators

  • <if:condition;then[;else]>: If condition is True, returns then; otherwise, returns else (if provided).

  • <eq:arg1;arg2[;arg3...]>: Returns True if all arguments are equal, False otherwise.
  • <neq:arg1;arg2>: Returns True if the arguments are not equal, False otherwise.
  • <lt:arg1;arg2>: Returns True if arg1 is less than arg2, False otherwise.
  • <gt:arg1;arg2>: Returns True if arg1 is greater than arg2, False otherwise.
  • <leq:arg1;arg2>: Returns True if arg1 is less than or equal to arg2, False otherwise.
  • <geq:arg1;arg2>: Returns True if arg1 is greater than or equal to arg2, False otherwise.

  • <and:arg1;arg2[;arg3...]>: Returns True if all arguments are True, False otherwise.
  • <or:arg1;arg2[;arg3...]>: Returns True if any argument is True, False otherwise.
  • <not:arg>: Returns the logical negation of arg.

  • <set:var;value>: Sets the variable var to value. Returns nothing.
  • <var>: Returns the value of the variable var.

  • <add:arg1;arg2[;arg3...]>: Returns the sum of all arguments.
  • <sub:arg1;arg2>: Returns the difference of arg1 and arg2.
  • <mul:arg1;arg2[;arg3...]>: Returns the product of all arguments.
  • <div:arg1;arg2>: Returns the quotient of arg1 divided by arg2. Returns {!! div: division by zero} if arg2 is zero.

  • <oneline:arg>: Returns arg with all line breaks replaced by spaces, and all \n replaced by a newline character.
